# Sentiment-Analysis-on-Amazon-Fine-Food-Reviews-ML-Project
End-to-end sentiment analysis on 568K Amazon Fine Food Reviews using 5 ML models (Logistic Regression, Naive Bayes, SVM, Decision Tree, Random Forest) with TF-IDF vectorization — AdaBoost, XGBoost, LSTM &amp; BERT planned.
This project applies machine learning to binary sentiment classification on the Amazon Fine Food Reviews dataset (568,454 reviews, 1999–2012). Reviews are classified as Positive (4–5 stars) or Negative (1–2 stars) using TF-IDF vectorization and five classification algorithms. SVM achieved the strongest performance with an F1 score of 96.18% and cross-validation mean of 96.14%. The project is actively being extended to include ensemble boosting models (AdaBoost, XGBoost, LightGBM), deep learning (LSTM), and transformer-based architectures (BERT/DistilBERT).
